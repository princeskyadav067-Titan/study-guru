[1:00 - ARCHITECTURE]
(show assets/architecture_diagram.png)
Let us look at how Study-Guru works behind the scenes.
(pause)
First, every query goes through our security checkpoint node to redact personal information, block injections, and filter academic cheating words.
If the query passes, it routes directly to the study coordinator, our central orchestrator agent.
The coordinator delegates the schedule layout to our specialized schedule agent, which uses the search study materials MCP tool to find textbooks.
At the same time, the coordinator asks the tutor agent to generate summaries and draft self-assessment quizzes using targeted MCP summary and question tools.
The compiled study plan then flows to our human review node, which pauses execution to wait for user approval or revision feedback.
If approved, it goes to the final output node; if rejected, it loops back to the coordinator with the feedback to refine the plan.

Our security checkpoint provides real-time PII redacting and injection blocks, logging every single decision to a structured JSON audit trail.
The backend MCP server connects seamlessly using stdio connections, running search study materials, get topic summary, and generate practice questions tools dynamically.
